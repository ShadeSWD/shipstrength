Неразрезная балка: эпюры и прогибы

Классическая задача СМК и сопромата. Задайте число пролётов и нагрузки — страница составит уравнения трёх моментов, найдёт опорные моменты прогонкой, построит эпюры Q и M, реакции и упругую линию (двойное интегрирование M/EI). Решение валидировано по учебным случаям: \(qL^2/8\), \(-qL^2/8\) на средней опоре двухпролётной, \(PL/4\), прогиб \(\frac{5qL^4}{384EI}\).

L, мq, кН/мP, кНa (от левой опоры), м
Схема балки: опоры шарнирные, по краям — моменты равны нулю

Знаки: положительный момент растягивает нижние волокна. Обратите внимание на отрицательные моменты над промежуточными опорами — ради них и существует метод трёх моментов.

Решение по шагам (с подстановками)

Как это решается вручную — по шагам

  1. Неразрезную балку мысленно режут на однопролётные, вводя неизвестные опорные моменты Mi (левая и правая крайние опоры шарнирные: \(M_0 = M_n = 0\)).
  2. Для каждой промежуточной опоры записывают уравнение трёх моментов: $$L_i M_{i-1} + 2(L_i + L_{i+1})M_i + L_{i+1} M_{i+1} = -6\left(\dfrac{A_i a_i}{L_i} + \dfrac{B_{i+1} b_{i+1}}{L_{i+1}}\right)$$ — справа «грузовые члены» от площадей балочных эпюр: \(qL^3/4\) для равномерной нагрузки, \(Pa(L^2 - a^2)/L\) для силы.
  3. Систему (она трёхдиагональная) решают — вручную последовательным исключением, здесь — прогонкой.
  4. Эпюра M = балочная эпюра каждого пролёта + линейная «подкладка» между опорными моментами; Q — её производная; реакции — скачки Q на опорах.
  5. Прогибы: \(v'' = M/EI\), дважды интегрируем, константы — из условий v = 0 на опорах.
