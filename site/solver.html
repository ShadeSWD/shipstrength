Неразрезная балка: эпюры и прогибы

Классическая задача СМК и сопромата. Задайте число пролётов и нагрузки — решатель составит уравнения трёх моментов, найдёт опорные моменты прогонкой, построит эпюры Q и M, реакции и упругую линию (двойное интегрирование M/EI). Решение валидировано по учебным случаям: qL²/8, −qL²/8 на средней опоре двухпролётной, PL/4, прогиб 5qL⁴/384EI.

L, мq, кН/мP, кНa (от левой опоры), м
Схема балки: опоры шарнирные, по краям — моменты равны нулю

Знаки: положительный момент растягивает нижние волокна. Обратите внимание на отрицательные моменты над промежуточными опорами — ради них и существует метод трёх моментов.

Как это решается вручную — по шагам

  1. Неразрезную балку мысленно режут на однопролётные, вводя неизвестные опорные моменты Mi (левая и правая крайние опоры шарнирные: M0 = Mn = 0).
  2. Для каждой промежуточной опоры записывают уравнение трёх моментов: LiMi−1 + 2(Li+Li+1)Mi + Li+1Mi+1 = −6(Aiai/Li + Bi+1bi+1/Li+1) — справа «грузовые члены» от площадей балочных эпюр: qL³/4 для равномерной нагрузки, Pa(L²−a²)/L для силы.
  3. Систему (она трёхдиагональная) решают — вручную последовательным исключением, здесь — прогонкой.
  4. Эпюра M = балочная эпюра каждого пролёта + линейная «подкладка» между опорными моментами; Q — её производная; реакции — скачки Q на опорах.
  5. Прогибы: v'' = M/EI, дважды интегрируем, константы — из условий v = 0 на опорах.
