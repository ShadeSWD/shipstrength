Глава 2. Неразрезные балки: метод трёх моментов

2.1. Откуда неопределимость

Балка на n+1 опоре имеет n+1 реакцию, а уравнений равновесия — два. «Лишних» неизвестных n−1. Метод трёх моментов выбирает их гениально: ставим над каждой промежуточной опорой шарнир и вводим парные моменты Mi. Каждый пролёт превращается в простую балку — всё из главы 1 применимо, — а неизвестные Mi находим из условия, что балка на самом деле целая.

2.2. Вывод уравнения

Условие целостности: угол поворота конца пролёта i слева от опоры i равен углу начала пролёта i+1 справа. Углы от нагрузки в простом пролёте выражаются через площадь ω грузовой эпюры M⁰ и её центр тяжести (правило Верещагина): \(\theta = \omega\cdot c/(L\cdot EI)\). Складывая вклады нагрузки и парных моментов, для каждой промежуточной опоры получаем

$$L_i\cdot M_{i-1} + 2(L_i + L_{i+1})\cdot M_i + L_{i+1}\cdot M_{i+1} = -6(B_{i,\text{ф}} + A_{i+1,\text{ф}}),$$

где грузовые члены \(B_{\text{ф}} = \omega\cdot c/L\), \(A_{\text{ф}} = \omega\cdot c'/L\). Для стандартных нагрузок они сведены в таблицы:

  • равномерная q по пролёту: \(6B/L = 6A/L = qL^3/4\);
  • сила P на отстоянии a (\(b = L - a\)): слева \(Pa(L^2 - a^2)/L\), справа \(Pb(L^2 - b^2)/L\).

Система трёхдиагональна (каждое уравнение цепляет три соседних момента) — решается прогонкой за один проход; так делает решатель, и он же печатает эти уравнения с вашими числами в «Решении по шагам».

2.3. Порядок расчёта — по шагам

  1. разбить балку на пролёты, выписать Li и нагрузки;
  2. посчитать грузовые члены каждого пролёта (таблица выше);
  3. составить уравнение трёх моментов для каждой промежуточной опоры (крайние моменты = 0 на шарнирных концах; консоль даёт известный момент);
  4. решить систему → Mi;
  5. эпюры: \(M(x) = M^0(x) + M_{\text{лев}}(1 - x/L) + M_{\text{прав}}\cdot x/L\), \(Q(x) = Q^0(x) + (M_{\text{прав}} - M_{\text{лев}})/L\);
  6. реакции — скачки Q на опорах; контроль: \(\sum R\) = суммарной нагрузке.

2.4. Контрольные эталоны

Двухпролётная балка L+L с q: \(M_1 = -qL^2/8\). Заделка ≡ бесконечный соседний пролёт. Симметрия должна давать симметричные моменты — быстрые проверки перед сдачей расчёта.
